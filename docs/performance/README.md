# Performance Evidence

Store measured performance results here.

Open Phase 0 measurement debt: [PHASE0_CAPTURE_MEASUREMENTS.md](PHASE0_CAPTURE_MEASUREMENTS.md).

Do not guess production budgets before Phase 0 measurements.

Track at minimum:

- device / OS / app build
- test duration
- battery delta
- thermal observations
- CPU
- memory
- bytes recorded per hour
- audio gaps
- process/service interruptions
- recovery result

Before public release, add Android Macrobenchmark tests and Baseline Profile generation for critical user journeys.
